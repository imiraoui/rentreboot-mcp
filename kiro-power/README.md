# RentReboot Kiro Power

Research NYC renter guides and rent data, and manage account-scoped apartment alerts with consent.

## Install

In Kiro, open **Powers → Add Custom Power → Import power from GitHub**, enter the repository URL and select the `kiro-power` folder if prompted. To import locally, clone the repository and select that folder using **Import power from a folder**. The power connects to the hosted MCP service; it does not run a local server.

Public renter guides and rent data work without an account. Personal tools require RentReboot OAuth consent and the applicable scopes.

After connecting, start a Kiro conversation about rentreboot and approve the relevant tool call. Access and billing follow the service's terms.
